# 🔍 Binary Reverse Engineering & Assembly Analysis (Patchwork)

## 📌 Overview
This repository contains a **Binary Reverse Engineering Challenge** completed as part of the **Computer Architecture** course at Bar-Ilan University.

The project involved analyzing a compiled x86 ELF executable (`patchwork`), disassembling its machine code, investigating function call stacks, and applying reverse engineering methodologies to uncover underlying program logic and control flow.

## ✨ Key Technical Skills Demonstrated
* **Binary Analysis & Disassembly:** Inspecting binary executables using debugging and disassembly tools (GDB / Objdump / Ghidra).
* **Control Flow Reconstruction:** Tracking memory addresses, stack frames, conditional jumps, and register manipulation.
* **Low-Level Debugging:** Setting breakpoints, analyzing assembly instructions, and monitoring runtime behavior.

## 🛠️ Tech Stack & Tools
* **Language / Architecture:** x86-64 Assembly, Machine Code
* **Debugging & Disassembly Tools:** `GDB` (GNU Debugger), `objdump`, `readelf`
* **Concepts:** Reverse Engineering, Binary Exploitation Fundamentals, Low-Level Control Flow, Stack Frame Analysis
